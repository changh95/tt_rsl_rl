# Agent memory (portable)

Durable notes for Claude Code sessions on this project, kept in the repository so that every machine starts with the same context
(Claude Code's own auto-memory lives per machine under `~/.claude/projects/`). `CLAUDE.md` imports `MEMORY.md`; read the linked files when relevant.

Rules for this folder:
- Update these files (not only the local auto-memory) when the owner gives a lasting instruction or a hard-won lesson is learned.
- **Never write here:** e-mail addresses, host names, IP addresses, user names or home-directory paths, PCI bus ids, board / ASIC ids,
  device-node numbers of a particular machine, credentials or tokens, other people's or other agents' activity, session ids, SHAs of commits that leaked data.
  Chip counts, mesh shapes, link widths, clocks, firmware versions and measurements are fine.
- Machine-specific facts (which chips, link widths, paths) go into the host settings the plan asks for, not here.
